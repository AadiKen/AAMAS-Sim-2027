# JBC holdout stage

This stage has not passed geometry acquisition. NMRI's Tokyo 2015 pages identify the official JBC hull geometry as IGES and list a later above-water geometry, but direct download was unavailable in this runtime. NMRI's later resistance data spreadsheet is also contact-gated. No surrogate geometry or reconstructed lines were admitted, and M1 generation was not attempted without the official source bytes.

The workshop source-attributed published summary values and their limitations are in `reference/jbc_reference.json`. They are not represented as byte-verified raw experimental records. Do not score the MANTA prediction from these values until official geometry is staged, the unchanged frozen M1 generator completes, and the package is hashed before the experimental values are read into the scoring step.

Frozen baseline revision 2 remains the generator contract. No generator source changed for this stage.

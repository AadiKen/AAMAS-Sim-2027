# Local runner protocol (MVP)

`manta-runner start` hosts the loopback API and the local process adapter. `POST /v1/jobs` accepts a complete canonical experiment, a unique `run_id`, a fixed mode (`scripted_waypoint` or `policy_evaluation`), optional seed, and optional policy ID. Arbitrary commands, executable paths, and shell fragments are not accepted. The adapter resolves and hashes the experiment, limits it to one vessel, a waypoint task, and at most 10,000 steps, then starts `bcod_sim.web.worker` as a separate process. The browser does not own the process.

The job directory is `<artifact_root>/jobs/<run_id>/`. `request.json` is the immutable submitted snapshot; `status.json` is atomically replaced. `frames.jsonl`, `metrics.jsonl`, and `logs.jsonl` grow during execution. A completed simulator run also has `run_<run_id>/` with the canonical `RunRecorder` manifest, resolved config, states, metrics, events, and provenance. Page reloads and backend restarts can read the job files. A worker that exits without a final status is marked failed when its owning server observes the exit.

Endpoints: `GET /v1/runners` reports the local adapter heartbeat and resources; `GET /v1/jobs` lists jobs; `GET /v1/jobs/{id}` reports state; `GET /v1/jobs/{id}/experiment` returns the submitted snapshot; `/frames`, `/metrics`, and `/logs` accept `offset` and `limit`; `/artifacts` lists hashed artifacts and checkpoint entries. `POST /v1/jobs/{id}/stop` writes a graceful-stop request checked between steps. `POST /v1/jobs/{id}/kill` hard-kills a live process owned by the current API process. Checkpoints are empty for these evaluation modes.

States: `QUEUED → RUNNING → COMPLETED|STOPPED|FAILED|KILLED`. A normal task success is `COMPLETED`, with `termination_reason=task_success`. A clean external stop is `STOPPED`. A policy compatibility or simulator exception is `FAILED` with a typed error and worker log. The runner does not implement training, pause/resume, or SLURM yet.

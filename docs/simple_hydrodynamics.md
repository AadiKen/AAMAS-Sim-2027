# Default CFD-free vessel generation

`bcod vessel generate` builds passive dynamics from a closed STL or OBJ surface without launching OpenFOAM. `bcod vessel identify` remains the explicit CFD campaign route. The generated body frame is BCOD FRD: X forward, Y starboard, Z down; DOFs are surge, sway, heave, roll, pitch, yaw.

```bash
bcod vessel generate \
  --geometry hull.stl --units m \
  --mass 180 --cg 0 0 0 \
  --speed-range 0 3 \
  --output vessel-package
```

Use `--known-length` in place of `--units` when one physical X dimension is known. Supply `--source-frame FPU` for X-forward/Y-port/Z-up source geometry. Optional inputs include `--draft`, `--water-density`, nine row-major `--inertia` entries, `--classification`, `--disable-bem`, `--bem-panel-target`, `--lut-samples`, and `--confidence-policy strict`. The default policy permits explicitly low-confidence packages; `strict` rejects them. STEP/STP inputs currently require a separate CAD-to-STL/OBJ triangulation tool and fail explicitly if passed directly.

## Stages and authority

1. Trimesh loads the source, welds vertices, removes duplicate and degenerate faces, repairs orientation, and requires a closed orientable solid. It records raw/processed hashes, bounds, component roles, and unresolved self-intersection limitations. It never reconstructs missing submerged geometry.
2. Exact triangle clipping computes volume and center of buoyancy. A mass/density bisection finds the waterline unless draft is supplied. Waterplane properties come from the mesh section; wetted area uses exact clipped-triangle area. Positive roll/pitch metacentric heights are required for the current equilibrium.
3. Deterministic vertex clustering attempts a smaller hydrodynamic mesh. It is accepted only if watertightness and configured volume, CB, waterplane, wetted-area, and dimension tolerances pass. Otherwise the full mesh remains authoritative. Both hashes and the attempt report are retained.
4. X stations of the bare hull components provide an elliptic-section strip added-mass baseline. Unsupported terms stay zero with low confidence, rather than receiving arbitrary values. Optional [Capytaine radiation problems](https://capytaine.org/master/user_manual/tutorial.html) use the zero-frequency limit for maneuvering added mass. A generated waterline lid is used for surface-piercing hulls; Capytaine excludes lid pressure from hull loads. The adapter guards panel count/aspect, finiteness, symmetry, positive added mass, strip comparison, and a second panel resolution when available. Radiation damping is recorded separately and never inserted into maneuvering damping. When Capytaine is absent or rejects a case, strip results are selected. The BEM extra installs Capytaine and fast-simplification into the active environment; the latter enables preservation-gated hull panelization.
5. Surge force is a signed speed curve based on ITTC-1957 skin friction. A guarded Michell potential-flow wave term is added only for thin, fine displacement monohulls (`L/B >= 10`, `Cb <= 0.55`, `Fn <= 0.45`); the numerical angular truncation must pass a sensitivity check. Other regimes use a low-confidence friction/form-factor fallback. The curve includes zero and a documented odd reverse extension. Wave, viscous-pressure, planing, transom, and multihull-interference uncertainty remains explicit.
6. Each bare-hull component has its own clipped submerged sections, carrying draft, beam, area, fullness, centroid, perimeter, lateral offset, and a bounded shape-dependent drag coefficient. The production `translation_shear_v5` law computes local lateral velocity `q=v+x*r`, a geometry-weighted mean `q_mean`, and uniform-drift transition weight `w=q_mean²/(mean_abs_u²+q_mean²)`. Its sectional force is `dY=-K|u_local|q(1-w)-0.5*rho*Cd*T*q*(w|q|+(1-w)|q-q_mean|)dx`; `dN=(x-x_ref)dY`. The linear term saturates with uniform drift while rotational shear retains cross-flow. Every term dissipates local lateral energy; zero and reverse surge are valid. Heave/pitch and roll still use documented low-confidence critical-damping fractions.
7. Exact mesh hydrostatics first solve heave, roll, and pitch equilibrium for the supplied mass and CG. The nonlinear restoring table is centered on that physical state and checked against the runtime trilinear interpolator. Plant6 evaluates this bounded table directly; it never clips the mesh during a simulation step. Out-of-grid motion raises an operating-envelope error.
8. A rigid-body mass matrix, selected added mass, linear damping, cross-flow, and speed curve feed the current Plant6 runtime. Generation checks positive inertia/added mass, passive energy over a signed speed/sway/yaw grid, and six lightweight free responses. A content-addressed request key skips repeat generation when source, parameters, optional Capytaine version, and pipeline code match.

## Package

The package contains `vessel.yaml`, `runtime_payload.json`, `coefficients.json`, `hydrostatics.json`, `added_mass.json`, `resistance.json`, `maneuvering.json`, `restoring_lut.json`, `processed_geometry.stl`, `hydrodynamic_mesh.stl`, `geometry.json`, `hydrodynamic_mesh.json`, `provenance.json`, `confidence.json`, `validation.json`, and `validation_report.md`. The compatible package schema remains `bcod-simple-hydrodynamics-v1`; the frozen production model is `bcod-passive-phase3a-1.0.0` in provenance. `runtime_payload.json` is the strict `VesselRuntime` payload; `vessel.yaml` includes package identity and the same physical model.

Stage 3B calibration hooks are named scales for surge resistance, cross-flow Cd, linear sway/yaw, added mass, and roll damping. `apply_passive_scales` applies them to a runtime payload while preserving nonnegative scales and the damping matrix's positive-semidefinite structure. Stage 3A does not apply vessel-specific calibration, model actuators, or require OpenFOAM. Stage 3B may later use measured response to calibrate uncertain passive terms and add control inputs.

## Present limitations

The current route requires a watertight solid, does not perform a generic global triangle self-intersection test, and detects only potential component overlaps from bounding boxes. A low-confidence label means that numerical execution and physical passivity have been checked, but quantitative prediction remains uncertain. Capytaine 3.0.0 was execution-qualified on a submerged sphere and a surface-piercing spheroid; the KCS 1:40 bare hull produced stable zero-frequency matrices at two panel resolutions. The [qualification record](../stage3_results/simple_hydrodynamics/bem_qualification/qualification.json) contains matrices, mesh preservation, and timings. KCS BEM total sway mass nondimensionalizes to 0.344 against the HMRI effective `(m+m_y)'` estimate 0.3702; inviscid zero-frequency radiation and finite-frequency viscous PMM identification are distinct quantities. The guarded thin-ship wave term was checked against a Wigley hull resistance reference, while KCS and fuller hulls remain on the low-confidence fallback. Full-hull displacement regressions, Savitsky planing, multihull interference, detailed appendage hydrodynamics, and validated roll damping are not implemented. Calibration is recommended when quantitative yaw/coupling, planing, multihull resistance, roll, or appendage effects matter.

## Phase 3A frozen validation

The [Phase 3A report](../stage3_results/simple_hydrodynamics/phase3a/phase3a_report.md) compares the frozen V1, V2, and final KCS coefficients and held-out forces, independent Wigley resistance, KCS towing resistance, generic fixtures, eight-hull fleet, and actual Plant6 free responses. The final KCS held-out medians are 13.1% for Y and 17.4% for N. Several polynomial derivatives remain poor, so the package is an uncalibrated Stage 3B starting plant with explicit low-confidence yaw/coupling, resistance, and roll domains.

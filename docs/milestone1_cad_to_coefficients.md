## Architecture

`simple_geometry.prepare_geometry` normalizes source meshes to FRD. The
configuration adapter in `input_contract.py` accepts a supplied mass or draft,
checks their consistency through `simple_pipeline.py`, and tags the origin of
mass, draft, CG and inertia. The existing section, hydrostatic, resistance and
added-mass implementations generate the passive model. `CanonicalVessel`
serializes the self-contained Plant6 runtime payload.

`coefficient_package.py` wraps that payload in a hash-checked
`manta-hydrodynamics-v1` contract. Its force-ownership table assigns rigid and
added-mass Coriolis to Plant6, hydrostatics to the restoring LUT, surge to the
resistance curve, lateral linear terms to the damping matrix, and nonlinear
lateral force to the sectional cross-flow model. A captive force surface is
rejected by this baseline loader, avoiding overlap with analytic terms.

The package states FRD force, velocity and moment frames and a body-origin
moment reference. Added-mass provenance distinguishes zero-frequency BEM from
the approximate strip fallback. Term metadata is copied from the generated
`coefficients.json` file. The package includes the full runtime payload, so
simulation does not require regeneration or Capytaine.

## Validation

Run:

```bash
bcod vessel generate --config vessel_input.yaml --output vessel_package
bcod vessel validate-coefficients vessel_package
```

The generation command runs coefficient validation automatically. The second
command reruns it on an existing package. Validation writes
`diagnostics/state_grid.csv`, JSON diagnostics,
`report/generation_report.md` and plots. It evaluates a three-dimensional
`u,v,r` grid, checks dissipative power, and compares an independent NumPy
coefficient evaluator with the Plant6 ledger. `physical_accuracy` is always
reported as `not externally validated`.

For a 4 × 2 × 1 m rectangular barge at 0.25 m draft, the analytic submerged
volume is 2 m³, waterplane area 8 m², and center of buoyancy 0.375 m in FRD z;
these agree with the production generator within the test tolerances. An
independent constant-section integral checks pure sway and pure yaw
cross-flow. The tested symmetric catamaran keeps two hull identities and
mirrored lateral loads. The small length perturbation test checks that a
0.1% change does not create a 20% wrench jump. The same alarm threshold is
checked for controlled vertex noise and a small waterline shift.

The [geometry sweep data](milestone1_figures/geometry_sweep.json) and
[geometry sweep plot](milestone1_figures/geometry_sweep.png) are generated by
`tools/run_manta_milestone1.py`. In the tested catamaran, pure-yaw damping
moment at 0.2 rad/s changed from −165.77 to −177.17 N m as half-spacing grew
from 0.7 to 1.3 m. The per-hull rotational axial-drag estimate has low
confidence; the test checks spatial sensitivity, not real-vessel accuracy.

## Remaining limitations

The spheroid production fixture reproduces the independent analytic surge and
sway added mass of a rigid-lid half ellipsoid within 5%; three UV-sphere mesh
resolutions change those terms by under 2% at each refinement. Length, beam,
draft, fullness and hull-spacing sweeps pass finiteness/continuity checks.
The optional appendage-position fixture has not been implemented.
Self-intersection detection is
limited by the current mesh stack. Structured failures are available through
the configuration adapter, while the lower-level generator still raises its
native exceptions.

Internal implementation checks passing does **not** imply physically accurate
coefficients for arbitrary real vessels.
